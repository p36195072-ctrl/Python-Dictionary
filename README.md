# Python-Dictionary
Python Dictionary Example

A beginner-friendly Python project that demonstrates how to store and access data using dictionaries in Python.

📌 Description

This program creates a dictionary named rahul that stores:

Name
Age
Profession

Then it accesses and prints the value of the "name" key.

🧠 Concepts Used

Dictionary in Python
Key-Value Pairs
Accessing Dictionary Values
print() function

💻 Code

rahul = {
    "name": "rahul",
    "age": 16,
    "profession": "programmer",
}

print(rahul["name"])

▶️ Example Output

rahul
